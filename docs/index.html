Every source, and how fresh it is

This is the complete list — nothing reaches this page from a source that is not in it. Each row links to the venue's own listing, to the raw feed the collector reads, and to that source's terms, so any claim here can be traced back and checked. Run python -m collector.verify to have every source fetched, parsed and reported on demand.

A source that fails keeps its last good records, labelled with when they were last seen, and the others still refresh. Venues with nothing to list — a public gallery, a museum open on weekdays — are visited on every run and only claim what their page still says: an age rule or a price disappears from here when it disappears from the venue's page. Nothing on this site is typed in by hand. Even so, the link on each card is the authority, not this page.
